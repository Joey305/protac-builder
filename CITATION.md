# How to cite PROTAC Builder

Please cite the published Zenodo software release:

> The Schürer Lab. (2026). *PROTAC Builder* (Version v2026.10) [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23374603

The hosted [citation page](https://protacbuilder.com/citation) provides this citation and an RIS download.

For a formal software citation, use the metadata in `CITATION.cff`.
