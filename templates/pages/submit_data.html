What not to submit

Please do not submit private patient data, confidential company data, unpublished proprietary structures without the right to share them, secrets, API keys, tokens, passwords, unsafe wet-lab protocols, unsupported activity claims, or large datasets without coordination.

Data and attribution expectations

  • Public contributions should include source information when possible.
  • Component suggestions should distinguish evidence from assumptions.
  • Published references, PDB IDs, database IDs, and tool-generated results should be cited or linked when relevant.
  • If a contribution is speculative, label it as speculative.
  • Do not upload restricted or confidential content.

Contact the project team

For coordinated updates, cross-tool questions, or contribution planning, contact the project team. Use the contact button if you need to discuss documentation updates, ecosystem synchronization, or more structured contribution paths than a public issue thread allows.
